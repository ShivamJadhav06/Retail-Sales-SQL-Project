# 🛒 Retail Sales SQL Project

This project is a **Retail Sales Analysis** using SQL. It includes a dataset and SQL queries that provide insights into sales trends, customer behavior, and product performance.

## 📁 Files Included

- `sda.sql`  
  Contains all the SQL queries used to analyze the retail sales data.

- `SQL - Retail Sales Analysis_utf (2).csv`  
  This is the dataset used in the project, containing sales records in CSV format.

## 🛠️ Tools & Technologies

- SQL (Structured Query Language)
- MySQL or any SQL-compatible database
- Microsoft Excel (used for data formatting and initial viewing)

## 📊 Project Highlights

- Total Sales and Revenue calculations  
- Top-selling products  
- Sales by region and date  
- Customer purchase patterns  
- Data cleaning and formatting for SQL

## 🔍 How to Use

1. Import the CSV file into your SQL database (e.g., MySQL Workbench).
2. Run the SQL queries from `sda.sql` in your database to perform analysis.
3. Explore and modify queries to gain deeper insights.
